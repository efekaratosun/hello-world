# Soru Günlüğü

Sana sorular sorarak günlük tutmanı kolaylaştıran, telefonda kullanılan dijital günlük.
Aklına bir şey gelmeyen günlerde bile uygulama sana yazacak bir şey bulur.

- Yol haritası: [ROADMAP.md](ROADMAP.md)
- Uygulama kodu: [`app/`](app/)

## Çalıştırma

```bash
cd app
npm install
npm run dev      # geliştirme sunucusu
npm run build    # üretim derlemesi (dist/)
```

Telefonda denemek için geliştirme sunucusunu `npm run dev -- --host` ile başlatıp aynı ağdaki telefondan açabilir, tarayıcı menüsünden **Ana ekrana ekle** diyerek uygulama gibi kurabilirsin.
